# Comic promotion prompts

1. Robot downloads an app and accidentally catches the download arrow like a frisbee.
2. A manifest scroll is longer than the robot is tall.
3. Two robots inspect a permission list with magnifying glasses.
4. A checksum is treated like a treasure map.
5. A tiny package rides a very serious delivery cart.
6. A robot stamps “owner review” on a comically large envelope.
7. A cloud rains harmless JSON brackets over a valley.
8. A robot asks another robot to read the terms before opening the door.
9. A warning sign politely waves instead of shouting.
10. A GitHub-shaped hill has branching paths and tiny apps.
11. A robot carries a signature key like a ceremonial baton.
12. A payment counter has two clearly separated checkout lanes.
13. A wrong-door robot finds the friendly catalog entrance.
All are wide, clean, text-free, original, and suitable for simple promotion cards.
