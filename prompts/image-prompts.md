# Image prompts

Shared style: original comical science-fiction landscape, expressive rounded robots, clean outlines, layered depth, teal/violet with warm amber, wide negative space, no text, no logos, no watermark.

- Home bazaar: robots browse tiny app stalls on rolling hills.
- Workshop: robot developer reads a glowing manifest scroll beside a comically oversized wrench.
- Membership: robot clubhouse on a hill with friendly visitors and floating badges.
- Support: tiny help desk and an oversized helping hand in a meadow.
